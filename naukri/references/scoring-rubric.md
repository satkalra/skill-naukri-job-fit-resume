# Scoring Rubric — Job–Resume Evidence Score

Full detail supporting §16 of `ats-guidelines.md`. Use this to award points per component, not just the headline weight.

Total = 100 points across 7 components. Hard gates (candidate-profile.md) are evaluated *before* this score and can block the application outright regardless of score.

## 1. Required-skill evidence — 25 pts

Score by the fraction of *required* (not preferred) skills that have Direct or Adjacent evidence in the career vault:

| Coverage of required skills | Points |
| ---------------------------- | -----: |
| ~100%, mostly Direct          |  23–25 |
| ~85–99%                       |  19–22 |
| ~65–84%                       |  13–18 |
| ~40–64%                       |   6–12 |
| <40%                          |    0–5 |

A skill with Weak or Missing evidence does not count toward coverage, even if the candidate lists it as an interest.

## 2. Core-responsibility evidence — 25 pts

Score by how well the candidate's actual accomplishments map to the job's core responsibilities (the duties listed first or repeated, per §5B), not just to tools.

| Fit | Points |
| --- | -----: |
| Has done this exact function at comparable scope | 23–25 |
| Has done a closely adjacent version of this function | 17–22 |
| Has partial or component-level experience | 9–16 |
| Only tangential experience | 1–8 |
| No evidence of this function | 0 |

## 3. Seniority and scope alignment — 15 pts

Compare years of experience, scope (team size, budget, system scale, customer count) and title level against the posting's level.

| Alignment | Points |
| --- | -----: |
| Matches or is one notch below with strong scope evidence | 13–15 |
| Roughly matches | 9–12 |
| Somewhat under- or over-qualified | 4–8 |
| Materially mismatched (should have failed a hard gate instead) | 0–3 |

## 4. Domain relevance — 10 pts

| Domain fit | Points |
| --- | -----: |
| Direct industry/domain experience | 9–10 |
| Adjacent domain (transferable concepts) | 5–8 |
| No domain experience but role doesn't require it | 4–6 |
| No domain experience and role emphasizes domain depth | 0–3 |

## 5. Demonstrated outcomes — 10 pts

Based on how many available bullets are quantified (§8) and how meaningful those outcomes are to this job.

| Quantified-bullet rate & relevance | Points |
| --- | -----: |
| ≥70% quantified, outcomes relevant to this job | 9–10 |
| 50–69% quantified | 6–8 |
| 30–49% quantified | 3–5 |
| <30% quantified | 0–2 |

## 6. ATS parseability — 10 pts

Award full points by default once the resume will follow §2–§3 (single column, standard headings, Month YYYY dates, DOCX+PDF, parse_check passes). Deduct for:

* Any table/text-box/graphic requirement from the source materials that can't be removed: −4
* Platform-specific rule violation (§3 platform notes) for a known ATS: −3
* Parse-check failure not yet resolved: −10 (must fix before sending)

## 7. Human readability and clarity — 5 pts

Simulated-recruiter check (Stage 8): is the target role obvious in 6–10 seconds, are top requirements visible in the top third, are achievements more prominent than duties?

| Clarity | Points |
| --- | -----: |
| Immediately clear and compelling | 5 |
| Clear with minor friction | 3–4 |
| Requires effort to understand fit | 1–2 |
| Confusing or generic | 0 |

## Applying thresholds

Sum the 7 components, then apply §16 thresholds (85+ apply · 78–84 apply if strategic · 68–77 only with referral · <68 skip), unless a hard gate already blocked the application.

Always show the component breakdown in the verdict, not just the total — the breakdown is what tells the candidate what to fix.
