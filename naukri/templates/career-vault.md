# Career Vault

One row per achievement/bullet. Never invent a row — every row must trace back to the master resume, a supplied document, or something the user confirmed in conversation. `Metric verified?` is `Yes` only when the user supplied the actual number; otherwise `No` (the bullet may still be used, unquantified, per §8 of ats-guidelines.md).

| Bullet text | Source (employer/role/project) | Skills/domain tags | Metric verified? | Notes |
|---|---|---|---|---|
| Example: "Rebuilt the weekly reporting pipeline in SQL and Excel, reducing manual reconciliation work by approximately 20%." | Northwind Analytics — Operations Analyst | SQL, Excel, reporting, process improvement | Yes | User confirmed the 20% figure directly. |
| Example: "Led onboarding-process redesign across three regional warehouses." | Contoso Logistics — Operations Lead | process improvement, vendor management, cross-site coordination | No | No quantified metric supplied yet — flag if a number would help. |
